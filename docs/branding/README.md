# Glee branding

Glee's mark is a green liquid puddle gently pulled upward by a small hovering UFO.

| Asset | Use |
| --- | --- |
| [Glee.png](../../Resources/Glee.png) | Transparent master artwork. |
| [Glee.icns](../../Resources/Glee.icns) | macOS app and installer icon. |
| [thumbnail-256.png](thumbnail-256.png) | Repository thumbnail and README. |
| [menu-white-96.png](menu-white-96.png) | Preview of the native menu bar symbol. |
| [MenuBarStatusIcon.swift](../../Sources/Glee/Support/MenuBarStatusIcon.swift) | Resolution-independent menu bar drawing. |

Use the green mark for the app and repository. The menu bar uses a native monochrome template: 24×20 points when idle, 32×20 with its activity dot. macOS supplies the appropriate light or dark tint.
