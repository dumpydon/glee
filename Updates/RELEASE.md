# Glee 2.0.0

Glee keeps your Mac awake from the menu bar. Choose a timer, an end time, or Unlimited; extend a session, control display sleep, and set battery limits.

This version is free. There is no account, activation key, subscription, or download fee.

## Install

Download the DMG from [Releases](https://github.com/dumpydon/glee/releases/latest), move **Glee.app** into **Applications**, and open it. The release supports macOS 14+, Apple silicon, and Intel.

If macOS blocks the downloaded app, review **System Settings → Privacy & Security → Open Anyway**. This release is locally signed and is not Apple-notarized.

## Closed-lid mode

Keep the lid open, connect your charger, and choose **Set up…**. Finish the helper installation using your Mac's administrator approval, then return to Glee, start a session, and wait for **Ready to close the lid**.

No Apple account or developer certificate is needed. A rebuilt or replaced app needs setup again. Closed-lid mode retains battery, time, temperature, and recovery safeguards.

If another sleep utility has a helper installed, remove its setup through that utility first.

## Updates

Updates are manual in this release. Download a new app when one is available. A separately configured Apple-signed distribution route supports signed automatic updates.
